# SWYNEX - Final Bioinformatics Report

## Project Overview
This project demonstrates basic bioinformatics data cleaning, statistical analysis, and visualization using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Tasks Performed
1. Created a sample biological dataset.
2. Identified missing values.
3. Removed duplicate records.
4. Replaced missing numerical values using median imputation.
5. Generated statistical summaries.
6. Visualized gene expression and GC content.
7. Exported cleaned data into CSV files.

## Results
- Original records: 6
- Records after cleaning: 5
- Missing values after cleaning: 0
- Duplicate records after cleaning: 0

## Files Included
- SWYNEX_Final_Bioinformatics_Report.ipynb
- SWYNEX_cleaned_biological_dataset.csv
- SWYNEX_statistical_summary.csv

## Note
This project uses a sample biological dataset for educational practice. It is not based on experimentally validated biological data.

This project helped develop practical knowledge of Python-based data cleaning, statistical analysis, and data visualization.
